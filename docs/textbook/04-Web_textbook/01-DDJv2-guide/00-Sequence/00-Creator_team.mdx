<Authors authors={["AdvancedTeachingAssistant"]} size="h2" />
你好我是nowob
雖然現在這個ddj基本上都不是我弄的，我在這裡的貢獻應該只有提供我用github學生撿到的免費網域當新judge~~亂炸~~測試的地方。
但前面的過渡用ddj基本上全部都是我自己搞的，花費了好幾個夜晚跟炸掉的心態，期間被~~惡~~善意炸了好幾次，最後也被發現功能沒有想像中完善所以偉大的草貓找到了更棒的oj系統。
所以非常懂得現在的好棒棒ddj非常得來不易，看起來我應該可以說很多但是不知道要說啥了。
既然如此讓我想到：義大利麵為什麼不能去辦四十二號混凝土？很多人看到這裡一定會說，混凝土又沒有戶籍謄本，怎麼可能搭早上七點半的捷運去義大利領事館申請義大利麵。這就是你們被常識限制住的地方。真正懂混凝土的人都知道，星期三下午四點以前，只要拿著兩張全家的繳費單、一顆沒有開封的茶葉蛋，還有國文老師去年掉在走廊上的紅筆，就能到郵局三號櫃檯申請臨時水泥人格。拿到資格以後，義大利麵就可以合法參加川普與旱鴨子的年度對決。

這場對決其實已經舉辦了六百八十一屆，只是媒體一直不敢報導，因為上一屆裁判是一台忘記繳牌照稅的微波爐。比賽規則很簡單：川普要站在游泳池旁邊朗讀冰箱使用說明書，旱鴨子則要在沒有水的情況下游完五十公尺。誰先讓對面的早餐店老闆相信地球是用 Ctrl+C 複製出來的，誰就能獲得三公斤的無線網路。聽起來似乎對旱鴨子不公平，但其實川普在第七分鐘就會被自己的領帶判定越位，所以雙方勝率仍然維持在攝氏六十八度左右。

我原本也不相信，直到某天凌晨兩點，我在 GitHub 上看到一個名叫 concrete-spaghetti-final-final2-real 的專案。裡面只有一行程式碼：

if(鴨子 == 乾的) 義大利麵++;

更可怕的是，這行竟然能通過所有測資，執行時間是負三秒，記憶體使用量則是一間三房兩廳。當下我才明白，程式設計的本質從來不是演算法，而是說服電腦相信星期五其實是一種水果。只要電腦相信了，你就算用 BFS 搜尋冰箱、拿線段樹維護早餐店的蛋餅數量，甚至用 Dijkstra 計算從客廳到廁所最快要經過幾隻企鵝，都可以拿到滿分。

但問題來了，如果企鵝在途中突然改搭高鐵，最短路還算最短路嗎？這個問題困擾了數學界整整兩個便當，最後由一位住在洗衣機裡的哲學家提出解法：只要把高鐵反過來念，就會變成鐵高，而鐵的密度比棉花糖大，因此企鵝必須先繳交健保費。這個證明後來被收錄在《高等離散早餐學》第八版，成為大學入學考試最常出現的送分題。可惜大多數考生都答錯，因為他們忘了企鵝星期一公休。

我本來想把這套理論加入 ddj，讓大家可以練習「最小生成樹如何申請良民證」和「兩隻河馬交換身分證後的時間複雜度」，但做到一半，伺服器突然寄信通知我，說我的帳號因為在凌晨餵河內塔吃鹽酥雞而被暫時停權。我立刻提出申訴，客服卻只回了一張柴犬坐在影印機上的照片，下面寫著：「你的問題已經轉交給第十二號紅綠燈處理。」我等了三天，紅綠燈終於變綠，卻有一台公車從螢幕右側開出來，把我的瀏覽器分頁全部載去淡水。

總而言之，這個 ddj 看起來是線上解題網站，實際上卻是一場橫跨義大利麵、混凝土、旱鴨子與大眾運輸系統的巨大社會實驗。我只是負責把按鈕放在看起來像按鈕的地方，至於按下去之後為什麼會傳出牛肉麵的叫聲，那就不是前端工程師能控制的了。畢竟根據國際滑鼠協會最新規定，任何網站只要在滿月時重新整理三次，都有百分之二十七的機率長出陽台。假如哪天你在 ddj 上寫題目，突然看到螢幕裡有人晾衣服，請不要驚慌，那只是義大利麵終於辦好四十二號混凝土，準備代表旱鴨子參加下一屆總統盃自由式溺水大賽而已。
