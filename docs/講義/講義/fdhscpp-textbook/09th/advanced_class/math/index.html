質數​

  • 只有恰好兩的因數 - 111和nnn
  • 111不是質數(也不是合數)
  • nnn以下的質數大約有nln⁡n\frac{n}{\ln n}lnnn​個
  • 任意數字nnn最多只有O(log⁡n)O(\log n)O(logn)個質因數

質數判斷​

  1. for i = 2 ~ n-1: if n%i==0 then n is composite，O(n)O(n)O(n)
bool is_prime(int x) {
	for (int i = 2; i < x; i++)
		if (x % i == 0) return false;
	return true;
}
  1. for i = 2 ~ sqrt(n): if n%i==0 then n is composite，O(n)O(\sqrt n)O(n​)
bool is_prime(int x) {
	for (int i = 2; i <= sqrt(x); i++)
		if (x % i == 0) return false;
	return true;
}
  1. 先判奇偶數，接下來只需要考慮iii是奇數就好，單純常數優化
  2. 6n±16n\pm 16n±1，先判2,32,32,3的倍數，接下來只需考慮i=6n±1i=6n\pm 1i=6n±1就好，一樣是常數優化
  3. 其實只需考慮iii是質數就好了，複雜度是O(nlog⁡n)O(\frac{\sqrt n}{\log n})O(lognn​​)，然而我們需要先想辦法找出≤n\le \sqrt n≤n​的所有質數

篩表 - sieve​

回想國小一開始教質數的時候，方法是先列出一張表寫著1~100，然後先不管1，從2開始，因為2沒被劃掉代表2是質數，之後把2的倍數都打叉，接下來3沒被劃掉因此3是質數，把3的倍數劃掉，然後4被打叉了所以是合數...一直下去
好好把這個做法實作出來就是sieve演算法

sieve(ver.1)​

vector<int> prime;
bool flag[n+1];
for(int i=2;i<=n;i++){
    if(!flag[i]){
        prime.push_back(i);
        for(int j=i+i;j<=n;j+=i)
            flag[j]=1;
    }
}

複雜度O(nln⁡ln⁡n)O(n\ln\ln n)O(nlnlnn)

sieve(ver.2)​

實際上iii的倍數中i2i^2i2以下的早就被刪掉了，所以jjj從i2i^2i2開始即可

vector<int> prime;
bool flag[n+1];
for(int i=2;i<=n;i++){
    if(!flag[i]){
        prime.push_back(i);
        for(int j=(long long)i*i;j<=n;j+=i)
            flag[j]=1;
    }
}

複雜度一樣O(nln⁡ln⁡n)O(n\ln\ln n)O(nlnlnn)，常數優化

根據上述我們就可以用O(nln⁡ln⁡n)O(n\ln\ln n)O(nlnlnn)時間預處理得到≤n\le n≤n的所有質數(同時也可以O(1)O(1)O(1)從flag陣列判斷≤n\le n≤n的數是不是質數)
配合前述質數判斷最後一種做法，可以O(nln⁡ln⁡n)O(\sqrt n\ln\ln n)O(n​lnlnn)預處理，O(nln⁡n)O(\frac{\sqrt n}{\ln n})O(lnnn​​)時間詢問

模運算​

由於很多題目值域可能會很大，為了維持在一個合理的範圍內(int以內之類的)，很多題目會是求答案mod  M\mod MmodM，(也就是取餘數)，因此模運算變得很重要

範例: DJ a264

定義​

amod  ma\mod mamodm 代表aaa取mmm的餘數
a≡b(modm)a\equiv b\pmod ma≡b(modm) 的意思是aaa和bbb同餘(模mmm)，實際上就是aaa和bbb取mmm的餘數相等，同時也等價a−ba-ba−b是mmm的倍數

trivia​

  • (a+b)mod  m≡(amod  m)+(bmod  m)(modm)(a+b)\mod m\equiv (a\mod m)+(b\mod m)\pmod m(a+b)modm≡(amodm)+(bmodm)(modm)
  • (a−b)mod  m≡(amod  m)−(bmod  m)(modm)(a-b)\mod m\equiv (a\mod m)-(b\mod m)\pmod m(a−b)modm≡(amodm)−(bmodm)(modm)
  • (a×b)mod  m≡(amod  m)×(bmod  m)(modm)(a\times b)\mod m\equiv (a\mod m)\times(b\mod m)\pmod m(a×b)modm≡(amodm)×(bmodm)(modm)

證明不難歡迎嘗試(令a=km+p,b=lm+qa=km+p,b=lm+qa=km+p,b=lm+q...)
根據上述可知模運算中的加減乘法都可以隨時做，也就是說就算有一連串的運算也不用算出最後的值再模，可以邊算邊模(每做一次運算就模之類的)

快速冪​

  • 求 abmod  ma^b\mod mabmodm

考慮分治: ab={1  ,  b=0(ab2)2  ,  b is even(ab2)2×a  ,  b is odda^b=\begin{cases}1\;,\;b=0\\(a^{\frac{b}{2}})^2\;,\;\text{b is even}\\(a^{\frac{b}{2}})^2\times a\;,\;\text{b is odd}\end{cases}ab=⎩⎨⎧​1,b=0(a2b​)2,b is even(a2b​)2×a,b is odd​
因此直接寫成遞迴code:

int pow(int a, int b, int m) {
	if (b == 0) return 1;
	int tmp = pow(a, b / 2, m);
	return (b % 2 == 1) ? tmp * tmp % m * a % m : tmp * tmp % m;
}

另一種版本: 考慮(ab2)2=(a2)b2(a^{\frac{b}{2}})^2=(a^2)^{\frac{b}{2}}(a2b​)2=(a2)2b​

int pow(int a, int b, int m) {
	if (b == 0) return 1;
	int tmp = pow(a * a % m, b / 2, m);
	return (b & 1) ? tmp * a % m : tmp;
}

迴圈版本: 我好懶的解釋或許可以自己看code想想看，反正遞迴不比較差會一種就好

int pow(int a, int b, int m) {
	int ret = 1;
	for (a %= m; b; b >>= 1, a = a * a % m) {
		if (b & 1)
			ret = ret * a % m;
	}
	return ret;
}

時間複雜度都一樣O(lg⁡b)O(\lg b)O(lgb)

注意到快速冪的這個做法其實不只能套用在整數快速冪，常見還有矩陣/多項式快速冪，除此之外此類分治也能應用在一些有相同性質的地方不一定只能用在快速冪

模逆元 (乘法反元素)​

constexpr int mod=1e9+7;
int pow(int a,int b=mod-2){
    int ret=1;
    for(;b;b>>=1,a=a*a%mod)
        if(b&1) ret=ret*a%mod;
    return ret;
}

大數​

若遇到題目的值域範圍超過基本資料型態所能存的範圍，那麼就要考慮自己實作大數
大數運算其實就是多項式運算的特例，例如:
12345=1x4+2x3+3x2+4x+512345=1x^4+2x^3+3x^2+4x+512345=1x4+2x3+3x2+4x+5並帶入x=10x=10x=10
當然也可以改變xxx的值換成不同進制的表示法，不過為了方便一般一定選x=10kx=10^kx=10k，而xxx越大會越省時間與空間但是要小心溢位:
12345=1x2+23x+4512345=1x^2+23x+4512345=1x2+23x+45帶入x=100x=100x=100
將數字轉換成多項式後，大數運算其實就是多項式運算而已，只是計算完後要好好處理進位

多項式/大數儲存方法​

多項式: ∑i=0n−1aixi\sum\limits_{i=0}^{n-1}a_ix^ii=0∑n−1​ai​xi
因此n−1n-1n−1次多項式可用長度為nnn的陣列來儲存，其中a[i]a[i]a[i]存xix^ixi次項系數
大數則是先選好個底數xxx，再來就好好把數字轉成多項式即可
處理進位則是在每次運算後，由低位到高位做進位a[i+1]+=a[i]/d,a[i]%=d其中ddd是底數

多項式加法​

ci=ai+bic_i=a_i+b_ici​=ai​+bi​
直接逐項相加即可，大數可能需要進位(最多進111位)，通常由低位到高位做同時順便處理進位，不用最後才處理
時間複雜度O(n)O(n)O(n)
若aaa是nnn次多項式，bbb是mmm次多項式，那麼ccc是max⁡(n,m)\max(n,m)max(n,m)次多項式
假設原本的值域是ddd (0≤ai,bi<d0\le a_i,b_i\lt d0≤ai​,bi​<d)，那麼ccc的值域是O(2d)O(2d)O(2d)

多項式減法​

ci=ai−bic_i=a_i-b_ici​=ai​−bi​
直接逐項相減即可，大數可能需要退位(最多退111位)，通常由低位到高位做同時順便處理退位，不用最後才處理
時間複雜度O(n)O(n)O(n)
若aaa是nnn次多項式，bbb是mmm次多項式，那麼ccc是max⁡(n,m)\max(n,m)max(n,m)次多項式，有可能會退化
假設原本的值域是ddd (0≤ai,bi<d0\le a_i,b_i\lt d0≤ai​,bi​<d)，那麼ccc的值域是O(d)O(d)O(d)

多項式乘法(卷積)​

ci=∑j=0iajbi−jc_i=\sum\limits_{j=0}^{i}a_jb_{i-j}ci​=j=0∑i​aj​bi−j​
(ci+j+=aibjc_{i+j}+=a_ib_jci+j​+=ai​bj​)
初始化ccc都是000，枚舉i,ji,ji,j做c[i+j]+=a[i]×b[j]c[i+j]+=a[i]\times b[j]c[i+j]+=a[i]×b[j]，大數可能需要進位，通常算完最後才處理
時間複雜度O(n2)O(n^2)O(n2)
若aaa是nnn次多項式，bbb是mmm次多項式，那麼ccc是n+mn+mn+m次多項式
假設原本的值域是ddd (0≤ai,bi<d0\le a_i,b_i\lt d0≤ai​,bi​<d)，那麼ccc的值域是O(nd2)O(nd^2)O(nd2)
